# Безопасность

Проект опубликован как исторический исходный код. Используются старые версии Python, aiogram, контейнеров и библиотек. Перед эксплуатацией обновите зависимости и проверьте весь стек в отдельном окружении.

Храните токены, `.env`, ключи CloudConvert, дампы БД, логи и документы пользователей вне Git. Если секрет попал в коммит, сначала отзовите его у провайдера, затем удаляйте из истории. Не прикладывайте секреты и персональные данные к публичным Issues.

Не открывайте PostgreSQL, Redis, Grafana и внутренний HTTP API в интернет. API управляющего бота не имеет аутентификации. Управляющая Telegram-группа должна быть закрыта и содержать только доверенных операторов. При конвертации PDF документы отправляются в CloudConvert.

Для сообщения об уязвимости используйте приватную функцию **Report a vulnerability** во вкладке Security этого репозитория. Укажите затронутую папку, версию, условия воспроизведения и последствия; используйте вымышленные данные и обезличенные примеры.
