# Telegram-боты расписания ККРИТ

Три приложения для загрузки и выдачи учебного расписания: бот управления, бот для студентов и бот для преподавателей.

| Папка | Назначение | Документация |
| --- | --- | --- |
| `bot-schedule-control-KKRIT` | Получение документов с Яндекс Диска, конвертация PDF через CloudConvert, разбор XLSX, хранение и внутренний HTTP API | [README](bot-schedule-control-KKRIT/README.md) |
| `bot-schedule-KKRIT` | Расписание учебных групп для студентов | [README](bot-schedule-KKRIT/README.md) |
| `bot-schedule-KKRIT-teacher` | Персональное расписание преподавателей | [README](bot-schedule-KKRIT-teacher/README.md) |

Это исторический проект. Он использует Python 3.9, aiogram 3 beta, Debian Buster и PostgreSQL 13. Перед рабочим развёртыванием требуется обновить стек и проверить сборку, парсеры и интеграции. Полная Docker-сборка и запуск Telegram-ботов для этой публикации не выполнялись.

## Как устроено

Управляющий бот получает документы, разбирает расписания и сохраняет их в своей базе. Два клиентских бота запрашивают `/hulls`, `/groups` и `/schedules` по внутреннему HTTP API и отправляют расписание пользователям Telegram.

У каждого приложения собственные PostgreSQL, Redis, `.env`, `pyproject.toml`, `poetry.lock` и `docker-compose.yml`. Сервисы взаимодействуют через Docker-сеть `control-KKRIT`; имя управляющего API в сети — `schedule-control-KKRIT-bot`. Общего Compose-файла в корне нет.

## Подготовка запуска

1. Клонируйте этот репозиторий и перейдите в папку нужного приложения.
2. Скопируйте его `.env.sample` в `.env` и заполните настройки. Для трёх приложений нужны отдельные Telegram-боты; токены в примерах демонстрационные.
3. Сначала подготовьте и запустите [бота управления](bot-schedule-control-KKRIT/README.md), заполните справочники и загрузите расписание.
4. Затем подготовьте [студенческого бота](bot-schedule-KKRIT/README.md) и [бота преподавателей](bot-schedule-KKRIT-teacher/README.md).

Например, подготовка конфигурации управления выполняется из его папки:

```sh
git clone https://github.com/kuttLoggin/kkrit-schedule-bots.git
cd kkrit-schedule-bots/bot-schedule-control-KKRIT
cp .env.sample .env
# Заполните .env и локальные ключи по README приложения.
docker compose config --quiet
```

Дальнейшие команды сборки, запуска и настройки приведены в README каждого приложения. Пароль PostgreSQL обязателен. Локальные порты трёх проектов должны различаться.

## Данные и безопасность

Рабочие токены, ключи CloudConvert, `.env`, базы, логи и пользовательские документы хранятся локально и исключены из Git. Для демонстраций используйте вымышленные данные. Сервисы БД, Grafana и внутренний API должны быть доступны только доверенным участникам; API не имеет собственной аутентификации.

Подробнее: [SECURITY.md](SECURITY.md).
