# Безопасность

Это исторический проект. В нём используются старые версии Python, aiogram и библиотек; актуальная безопасность зависимостей не гарантируется. Перед реальным развёртыванием обновите и проверьте стек в отдельном окружении.

Не размещайте токены, `.env`, ключи CloudConvert, дампы БД, логи и рабочую папку `data/` в Git. Если настоящий секрет попадал в историю, сначала отзовите его у провайдера, затем очистите историю всех затронутых веток и тегов. Удаления файла в новом коммите недостаточно.

Не открывайте PostgreSQL, Redis, Grafana и внутренний HTTP API для интернета. Управляющая Telegram-группа должна быть закрыта и состоять только из доверенных операторов. Бот управления отправляет PDF в сторонний сервис CloudConvert; учитывайте это при выборе документов.

Не публикуйте эксплуатационные данные пользователей. Находки безопасности сообщайте владельцу приватно через контакт его GitHub-профиля; не прикладывайте действующие ключи и личные данные в публичные Issues.
